# @nestos/dream

This package contains Dream's host-independent domain mechanisms. Host adapters
provide authorization, storage and bounded source readers; never treat model output
or configured identifiers as proof of access. Revalidate source grants before
returning derived content. Preserve stable operation identity and durable receipts
across retries. Do not execute suggestions or modify source projects implicitly.

The current source scanner and application evidence store are preliminary. Do not
advance a production watermark before derived results are durably settled together
with the associated receipt, or by an equivalent recoverable protocol.
