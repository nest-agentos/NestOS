# WebDAV 文件连接

工具箱的 Cells 连接表单中将「文件协议」选为 WebDAV，填写集合 URL、名称及 Basic、Bearer 或匿名认证，先测试再保存。Cells 提供的地址形如 `/dav/<alias>/<项目相对目录>/`；集合由 Cells 的导出及权限配置决定，不把 NestOS 本地项目 ID 直接当作服务端物理路径。凭据复用现有连接私密存储，不进入连接公开投影或诊断日志。

保存或查看连接只进行配置和读取，不挂载文件系统。打开该连接后点击「挂载 WebDAV」，选择本地目标项目、集合内的目录、挂载位置和读写方式。位置必须是未占用的一级目录，例如 `/tlj`。挂载完成后从该项目的文件界面浏览、创建和编辑文件。连接概览逐个展示挂载，并提供状态、重连和卸载入口。重启后保留连接配置，不恢复 WebDAV 挂载；既有 Cells 原生连接及其历史挂载保持原语义。

WebDAV 是独立文件协议：连接测试通过 OPTIONS 和 PROPFIND，文件访问使用 PROPFIND、GET、PUT、MKCOL、MOVE、DELETE、LOCK、UNLOCK，不调用原生发现、项目或 Agent API。WebDAV 连接不提供原生 Session、Agent 或执行能力；Cells 原生连接继续提供这些能力。

## 写入与恢复

- 只读挂载在 VFS 中禁止修改；选择读写不会提升服务端权限。OPTIONS 的 Allow 声明方法支持，不等于主体写授权，服务端拒绝时保留 EROFS/EACCES 及安全业务错误码。
- GET 返回的 ETag 随正文交给编辑器，PUT 使用该读取版本的 If-Match；创建使用 If-None-Match `*`。不以写前 stat 替换读取版本。缺少强版本时拒绝替换，要求重新读取和比较。
- 服务声明 DAV 锁能力时，替换现有文件先申请有限独占锁，PUT 同时提交锁令牌和原读取版本，结束后 UNLOCK。锁超时或版本改变不会降级为无条件覆盖。锁释放失败保留独立诊断，有限租约最终由服务端回收。
- MOVE 设置 Overwrite `F`，集合须为空才能删除。服务在 OPTIONS 声明 `X-Cells-DAV-Structural-Conditions: if-match` 时，MOVE 先取源资源 ETag，DELETE 使用现有检查读到的 ETag，两者都提交 If-Match。不支持元数据、递归删除、COPY、跨集合 MOVE 或范围读取。
- 每个修改请求分配 operationId；日志包含方法、阶段、结果、错误分类和耗时，不含认证头、锁令牌、路径、正文或完整参数。VFS 和 RPC 保留 operationId、outcome 与安全 remoteCode。
- 断线、上传失败和服务端未知结果不会自动重放。未知或 partial 结果在该来源生命周期中阻止后续修改，仍允许读取及释放已知锁；须保留本地副本，核对远端实际结果，再由用户决定恢复。重新挂载不能证明旧操作未提交。
- 文件编辑复用现有本地草稿恢复及冲突比较入口。冲突、权限或锁失败保留脏状态；未知结果显示原操作身份。Cells 的结果查询是其可选原生辅助能力，独立 WebDAV 客户端不依赖该 API，也不会因账本不可用推断未提交。
