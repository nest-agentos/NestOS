# Isolated HTTP decision-page performance

`node scripts/verify-http-decision-performance.mjs` runs the frozen baseline and current source against independent LocalFS/SQLite stores and fresh test CAs. Set `KANBAN_BROWSER` to Chromium and `PERF_PLAYWRIGHT` to the Playwright entry module. `PERF_ENV` defaults to `_nestos/kanban/retained-environment`; it must contain a baseline source tree with its own lockfile installation at `baseline/`, and corresponding Vite HTTP UI builds at `http-baseline-ui/` and `http-current-ui/`. The current script records the frozen root and two modified library revisions for this task. Prepare those builds from the matching source trees before running; never use a live profile or production certificates.

The fixture creates one board, 100 confirmed decisions without project references, two independent local projects, and no sessions; background application startup has completed before measurement. Each sample uses a fresh browser context and an independent server/store. The boundary starts before browser navigation and ends after 50 decision rows and the status filter are present. All browser HTTP requests are counted, including static files and the event stream; application batches count each contained logical call. Unknown packet kinds and browser/HTTP errors fail the run. The existing performance budget gates are unchanged. Output is `http-decision-comparison.json` in `PERF_ENV`; temporary process cleanup must be confirmed before accepting it.
