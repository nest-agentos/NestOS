# Cells 服务交付插件

- 本包是独立 RuntimeServiceControl 实现，Cells 构建和 Firecracker 切换规则不进入核心协调层。
- 控制器仅从管理员私有配置加载；运行模块安装到共享项目之外的版本目录。项目和模型只能选择已注册目标，不能授予服务控制权限。
- 构建冻结源提交，使用独立 Cargo 输出目录；制品通过完整摘要和源版本核验。不得在构建时改写正在运行的可执行文件。
- 切换前持久化请求，使用 SQLite OS 锁串行；未知结果只核对原身份，不重复重启。成功必须核对真实 VM 绑定、服务就绪及运行进程的二进制哈希。
- 保留现有服务配置、持久根盘和会话；不创建、删除或重定位 Native Session。
- 日志只记录操作标识、阶段、结果、耗时和安全错误码，不记录凭据、命令参数或会话正文。
- 单元测试用 `node --test tools/cells-deployment/test.mjs`，验收驱动遵循根目录临时进程作用域约定；正式服务控制沿用原生命周期。
